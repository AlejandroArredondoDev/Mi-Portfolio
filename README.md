## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5 semántico, CSS3 (Flexbox y Grid), Web Responsive (Mobile First)
- **APIs & Servicios:** FormSubmit API (Gestión de envío de formularios de contacto)
- **Despliegue & Herramientas:** GitHub Pages, VS Code, Git

---

## 📌 Secciones Principales

- **Inicio:** Presentación profesional con enlaces directos a CV, LinkedIn y GitHub.
- **Sobre Mí:** Resumen de trayectoria profesional previa y barras de nivel en stack técnico.
- **Proyectos:** Muestra interactiva de desarrollos web realizados.
- **Formación:** Módulos académicos e hitos formativos (DAW y Certificación Microsoft AZ-900).
- **Contacto:** Formulario funcional de contacto.
